LanLink 局域网远程控制 - 快速使用说明
====================================

【v4 改了什么】一句话
1. 界面文字终于看得清了：以前跟随系统主题，在你这种浅色系统上会变成
   "近黑底 + 深灰字"。现在固定深色 + 自带调色板（正文提亮到接近白），
   字号从 12.5px 加到 15.5px，所有面板都显式上底色，不再透出黑底。
2. 键鼠"突然不能操作"有自愈机制了：
   - 控制端每 0.5 秒探一次被控端的键鼠通道，发现"你在操作但事件没进去"
     或"注入被系统拒绝"，顶部会弹红条并自动修复（先软修复，两次无效
     自动断线重连）。
   - 手动兜底：按 F8 = 修复键鼠，按 F9 = 立即重连，工具栏上也有按钮。
   - 状态栏常显"键鼠 注入 N"：数字在涨说明事件确实到了被控端；
     不涨就是被卡住了，界面会自己报出来。
   - 重连一定会拿到干净会话：新连接直接顶掉被控端上的旧会话，
     所以"断开再连一次"现在是真的有用（以前旧会话卡着会拒绝新连接）。

【第一次运行前】
先把整个 zip 解压到一个普通文件夹（例如 D:\LanLink），确认
lanlink.exe 和三个 bat 在同一个目录里。不要在压缩包预览窗口里直接
双击 bat：Windows 只会把 bat 临时解压出来，会提示找不到 lanlink.exe。
如果解压后 exe 不见了，多半是 Windows Defender/杀软误报隔离：
打开"Windows 安全中心 -> 病毒和威胁防护 -> 保护历史记录"，还原它，
并把解压目录加入"排除项"。

【被控端 B（要被控制的那台）】
1. 解压到可写目录，例如 D:\LanLink。
2. 双击"启动被控端.bat"。
   如果 Windows 提示"已保护你的电脑"，点"更多信息 -> 仍要运行"；
   或右键 zip/exe -> 属性 -> 勾选"解除锁定"。
3. 点界面上的"放行防火墙（需 UAC）"，在 UAC 弹窗点"是"。
4. 记下界面显示的地址，例如 192.168.120.120:47800。
5. 窗口保持打开。需要控制管理员窗口时，右键"以管理员身份运行"
   lanlink.exe --agent。

【双屏/多屏】可选：只共享主屏（帧率翻倍）
默认共享整个虚拟桌面（例如双屏 3840x1080），如果只需要主屏：
    lanlink.exe --agent --primary-only
实测同一台双屏机：整个虚拟屏约 16.8 fps，只抓主屏约 36.2 fps。
启动时决定，运行中不能切换。

【控制端 A（操作的那台）】
1. 双击"启动控制端.bat"。
2. 点"扫描局域网"找到 B 后点"连接"；
   或直接在"目标"里填 B 的 IP:47800 点"连接"。
3. 连上后看到 B 的桌面。用鼠标点一下远程画面，键盘才会发给 B
   （点画面同时会把窗口焦点抢回来，不用担心焦点丢了键盘失灵）。
4. 工具栏：
   - 连接 / 断开 / 立即重连（F9）
   - "控制中"点一下就变"只看画面"：只收画面、一个键鼠事件都不发，
     适合只想看进度、不想误操作别人的电脑；再点一下恢复控制。
   - "修复键鼠"（F8）：远端键鼠不动时点它，先软修复，无效自动重连。
   - 剪贴板同步、发送文件、画质/帧率(1-60)/全屏(F11)、释放键鼠。
   - 状态栏显示 fps、MB/s、延迟、解码耗时，以及"键鼠 注入 N"。

【键鼠不动怎么办（v4 排查顺序）】
看状态栏"键鼠 注入 N"这个数字：
- 数字在涨，但 B 上没反应 -> 事件已注入到系统，问题在 B 的目标窗口：
  被控端是普通权限而目标是管理员窗口？或目标程序拦截了 SendInput
  （游戏反作弊、部分安全软件、UAC 安全桌面）。让被控端用管理员运行。
- 数字不涨，顶部弹红条 -> 程序已检测到通道卡住，会自动修复，
  一般 1-2 秒恢复。想手动：按 F8（修复键鼠）或 F9（立即重连）。
- 什么都不动、也没报警 -> 先点一下远程画面，再按 F8。
- 远端按键像是"卡住"了 -> 按 F8，或点"释放键鼠"；
  切到"只看画面"也会让被控端立刻松开所有键。
- UAC 安全桌面、Ctrl+Alt+Del、锁屏界面无法注入，这是 Windows 的限制。

【退出远程控制】
- 连按两次 Esc 可以断开连接并退出全屏（第一次按下时画面下方会提示
  "再按一次 Esc 退出远程控制"，400ms 内没有再按一次即取消）。
- 也可以直接点顶部"断开"，或者关掉控制端窗口。

【VPN 注意】
- 目标地址填 B 的 192.168.x.x 局域网 IP，不要填 VPN 分配的 10.x 地址。
- 防火墙规则覆盖所有网络配置文件，VPN 切换网络后依然有效。
- 如果 VPN 客户端开了"禁止访问本地局域网"、kill switch 或强制隧道，
  应用层无法绕过：请在 VPN 设置里放开，或把 192.168.x.0/24 加入排除。
- 扫描不到时，直接手动输入 IP；UDP 广播可能被拦，TCP 直连通常可用。
- 自己测通不通：
    ping 192.168.120.120
    Test-NetConnection 192.168.120.120 -Port 47800
  第二条显示 TcpTestSucceeded : True 就说明端口通。

【剪贴板】
- 两端都有开关，任意一端关闭就不同步。
- 支持文本和图片，双向同步，一般 80ms 内完成。
- 在 A 上按 Ctrl+C/X/V 时，会优先推送一次剪贴板，粘贴到的是最新内容。
- 大图片或超大文本会让画面短暂卡一下，属正常。
- 剪贴板里是图片时，A 按 Ctrl+V 不会额外补推（系统只在有文本时
  才产生粘贴事件）；图片本身仍会正常双向同步。

【文件传输】
- 当前只支持 控制端 A -> 被控端 B。
- B 的保存目录显示在界面上，通常是：
    C:\Users\<用户名>\Downloads\LanLink
  不可写时自动降级到：
    C:\Users\<用户名>\LanLinkDownloads
- 重名文件自动加 (1)，不会覆盖。

【开机自启】
- 在 B 上勾选"开机自动启动"，会写入当前用户 HKCU Run，不需要管理员。
- 移动 exe 位置后需要重新勾选一次。

【已知限制】
- 仅 Windows 10/11 x64、IPv4、同一局域网。
- 无加密/无鉴权：只在可信局域网自用，不要暴露到公网。
- UAC 安全桌面、Ctrl+Alt+Del、锁屏界面无法控制。
- 多显示器默认合成一个虚拟桌面；要只共享主屏用 --primary-only。
- 帧率受 GDI 抓屏限制：单屏 1080p 约 30-36 fps，双屏合成约 16-20 fps。
- 没有音频，没有 B -> A 的文件传输。
- 普通权限被控端控制不了管理员窗口；用管理员身份运行被控端。
- 无版本控制：升级新版时要手动替换 exe。

【常见问题】
- 提示找不到文件 lanlink.exe：没有先解压，或 exe 被杀软隔离。看开头。
- 提示"监听 TCP 47800 失败"：已经有一个被控端在运行，关掉多余实例。
- 扫描不到：不同 WiFi？防火墙没放行？AP 隔离？VPN 禁止局域网？手动填 IP 试。
- 画面黑屏/一直"等待远程画面"：B 在锁屏/UAC/DRM 播放？多屏主屏休眠？
  把"最大宽度"调到 1280、"画质"调到 50 试试。
- 键鼠没反应：见上面【键鼠不动怎么办】。
- 帧率低：看 B 的日志里"抓屏 xx ms"，双屏合成可加 --primary-only。
- 文件失败：看 B 的日志和保存目录权限，以及磁盘空间。
- 端口检查：netstat -ano | findstr :47800

详细说明见 README.md。
